# Arduino Uno R4 Minima 2サーボ角度制御モジュール (近藤科学 KRS-786ICS対応)

Arduino Uno R4 Minima を使用して、2台のロボット専用サーボモータ **近藤科学 (KONDO) KRS-786ICS**（D9: 上下動用 / D10: 開閉用）をUSBシリアル通信で高精度に角度制御するプログラムです。

KRS-786ICS のPWMパルス幅仕様（`700μs 〜 2300μs`、ニュートラル `1500μs`）に最適化され、**現在位置を0度にするゼロ点リセット（`ZERO`）** や **相対移動（`+10`, `-15`）**、**スムーズな速度制御** に完全対応しています。

## 🔌 配線 & ピン割り当て ([`Config.h`](file:///C:/Users/GEIZYUTU/DEV/A-MU/Config.h))

### サーボモータ接続
| サーボ | 役割 | 信号ピン (Uno R4) | パルス幅 | 可動範囲 |
| :--- | :--- | :--- | :--- | :--- |
| **Servo 1** | 上下方向 (Elevation) | **D9** | 700〜2300μs | 0° 〜 180° |
| **Servo 2** | 開閉 (Gripper) | **D10** | 700〜2300μs | 0° 〜 180° |

### シリアル通信ポート (併用可能)
| ポート種別 | Arduino ピン | ボーレート | 接続先・用途 |
| :--- | :--- | :--- | :--- |
| **USB シリアル** | Type-C USB (`Serial`) | **115200 bps** | PC（シリアルモニタ / Python等） |
| **GPIO シリアル** | **D5 (RX)** / **D6 (TX)** | **9600 bps** | 外部マイコン (ESP32 / Raspberry Pi / 外部制御機器等) |

```text
【配線例】
[外部電源 6V~7.4V (+)] ───── 各サーボの赤線 (VCC)
[外部電源 GND (-)]     ─┬─── 各サーボの黒/茶線 (GND)
                        ├─── Arduino GND
                        └─── 外部シリアル機器 GND (GND共通化)

[Arduino D9]  ────────────── Servo 1 (上下) 信号線 (白またはオレンジ)
[Arduino D10] ────────────── Servo 2 (開閉) 信号線 (白またはオレンジ)

[Arduino D5 (RX)] ────────── 外部シリアル機器 TX
[Arduino D6 (TX)] ────────── 外部シリアル機器 RX
```

## 💻 角度制御シリアルコマンド一覧 (USB: 115200 bps / GPIO: 9600 bps)

### 1. 各サーボの角度指定 & 相対移動
| コマンド | 説明 | 例 |
| :--- | :--- | :--- |
| `S1:<角度>` または `UP:<角度>` | Servo 1 (D9) の角度を指定 (0〜180°) | `S1:90` / `UP:120` |
| `S1:+<角度>` / `S1:-<角度>` | **現在位置からの相対移動** | `S1:+15` (+15度) / `S1:-10` (-10度) |
| `S1:<角度>:<速度>` | 角度と移動速度(度/秒)を指定 | `S1:90:30` (30°/秒でゆっくり移動) |
| `S2:<角度>` または `GRIP:<角度>` | Servo 2 (D10) の角度を指定 | `S2:45` / `GRIP:60` |
| `S2:+<角度>` / `S2:-<角度>` | Servo 2 の相対移動 | `S2:+5` / `S2:-5` |
| `OPEN` / `CLOSE` | グリッパーのワンタッチ開閉 | `OPEN` / `CLOSE` |

### 2. 2軸同時の制御
| コマンド | 説明 | 例 |
| :--- | :--- | :--- |
| `<S1角度>,<S2角度>` | **数値2つで直接指定（最短入力）** | `90,45` や `90:45` や `90 45` |
| `<S1角度>,<S2角度>,<速度>` | 数値2つ＋移動速度を指定 | `90,45,30` |
| `POS:<S1角度>:<S2角度>` | 2つのサーボの目標角度を設定 | `POS:90:45` |
| `REL:<S1増減>:<S2増減>` | **2つのサーボを同時に相対移動** | `REL:10:-5` (S1+10°, S2-5°) |

### 3. ゼロ点リセット（原点キャリブレーション）
| コマンド | 説明 |
| :--- | :--- |
| **`ZERO`** または **`TARE`** | **現在のアーム位置を基準の「0度」として登録**<br>（以降、`S1:0` でその位置に戻り、`S1:20` でそこから+20度動きます） |
| `ZERO:S1` / `ZERO:S2` | 指定したサーボのみ現在位置を「0度」にする |
| **`ORIGIN`** または **`RESET_ZERO`** | ゼロ点オフセットを解除し、物理絶対原点（0〜180度）に戻す |

### 4. 安全・システムコマンド
| コマンド | 説明 |
| :--- | :--- |
| `FREE` または `DETACH` | サーボを脱力・フリー状態にする（手動で動かせます） |
| `ATTACH` または `ON` | サーボを通電・トルクONにする |
| `STATUS` | 各サーボの現在角度、Raw角度、ゼロ点オフセット、動作状態を表示 |
| `HELP` | コマンド一覧を表示 |
