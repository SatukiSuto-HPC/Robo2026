# Robo2026 シーケンスエディター

Robo2026ロボットの動作シーケンスをGUIで作成・編集し、Pythonの制御コード（`task_mode.py`, `config.py`）を自動生成するツールです。

## 必須要件

- Python 3.x
- pyserial (`pip install pyserial` などを実行してください。インストールされていない場合はシリアル通信機能のみ無効化されます。)
- tkinter (Python標準ライブラリ)

## 起動方法

```bash
python sequence_editor.py
```

## 使い方

1. **タスクの編集**
   - 左側の「タスクリスト」でタスクを選択し、右側の「タスクプロパティ」で設定を編集します。
   - 「追加」で新しいタスクを作成できます。「上へ」「下へ」で順番を入れ替えることができます。

2. **タスクの種類**
   - `LINE_TRACE`: ライントレース移動。完了条件(QR, 時間, 全ライン検知)を設定できます。
   - `ARM_MOVE`: アーム制御。S1(上下)とS2(グリッパー)の角度、動作完了までの待機時間を設定します。
   - `WAIT`: 指定時間待機。
   - `STOP`: モーターを停止。
   - `GOAL`: シーケンスの終了地点。

3. **パラメータの設定**
   - 画面下部で `config.py` に出力されるライントレース関連のパラメータを編集できます。「パラメータ保存」を忘れずに押してください。

4. **ファイルの保存・読み込み**
   - 画面右上の「保存」「開く」ボタンで、作成したシーケンスをJSONファイルとして保存・読み込みできます。

5. **コードの生成**
   - 画面右上の「コード生成」ボタンを押すと、現在の設定に基づいて `task_mode_generated.py` と `config_generated.py` のプレビューが表示されます。
   - ダイアログ内の「ファイルに保存」を押すと、ツールと同じディレクトリにファイルが自動生成されます。

6. **シリアル通信 (オプション)**
   - Arduino等のマイコンに直接コマンドを送信・動作確認するための機能です。
   - ポートとBaudレートを指定して「接続」し、コマンドを入力して「送信」ボタンを押します。
