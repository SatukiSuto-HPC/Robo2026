# MakerLine ライントレースカー & 2軸ロボットアーム MicroPython 統合制御システム

本プロジェクトは、**MakerLine 4連デジタルセンサーを用いたステッピングモーター駆動ライントレースカー**と、**2自由度ロボットアーム制御・動作ティーチングシステム**をESP32上の **MicroPython** で完全に統合したファームウェアです。さらに、Raspberry PiからのUART連携および、**Arduino UnoへのUARTデータ中継機能（ブリッジ）**も実装しています。

---

## 🎯 主な機能・特徴

1. **コルーチンライクな非同期・協調マルチタスクループ**:
   - Webサーバー処理とモーターのステッピング制御（マイクロ秒単位のパルス生成）を1つのメインループ (`main.py`) で非同期的に処理。
2. **P制御による滑らかなライントレース**:
   - 4連デジタルセンサー（S0〜S3）の検知状態に応じてDRV8825ステッピングモータのパルス幅（速度）を動的にP制御し、滑らかなライントレースを実現。
3. **【新機能】Arduino Unoへの初期化データ送信（UART連携）**:
   - ESP32起動時に Arduino Uno (`UART1`) に対して初期状態を示すデータ（`"0,175\n"` など）を送信し、システム全体の状態を同期します。
4. **マーカー検知時のArduino連携**:
   - すべてのラインセンサがラインを同時に検知（交差点や停止線）した場合に台車を一時停止。ロボットアームの制御やティーチング動作は **Arduino Uno へ完全に委譲** されています。
6. **Wi-Fi APモード & Webコンソール（スマホ・PC遠隔閲覧・操作）**:
   - ESP32自身がアクセスポイント（**SSID: `zeni`**）を構築。ルーター不要。
   - ブラウザで `http://192.168.4.1` にアクセスすると、モダンなダークテーマのWeb UIから、各センサの状態・アーム座標のテレメトリ閲覧、および手動での `START`/`STOP`/`REC`/`PLAY` コントロールが可能。

---

## 📐 システム構成と作成済みファイル群

1. `config.py`: ハードウェアピン、速度パラメータ、通信設定などの統合管理
2. `boot.py`: 起動時のWi-Fiアクセスポイント設定（`zeni` / `hogehoge`）と初期化
3. `line_follower.py`: 4連センサのステータス取得、DRV8825駆動ロジック、ライントレース制御
4. `web_server.py`: MicroPython socket HTTPサーバー（フロントエンドUI配信、JSON API提供）
5. `main.py`: 非同期協調マルチタスクによるシステムのメインイベントループ
6. `index.html`: リッチで洗練されたダークテーマのフロントエンドダッシュボード画面

## 🔌 ハードウェア接続（ピンアサイン一覧）

マイコン: **ESP32 (MicroPython環境)**

### ① MakerLine（4連デジタルラインセンサー）
| センサー位置 | ESP32 ピン | 備考 |
| :--- | :--- | :--- |
| **S3 (左外側)** | **GPIO 32** | デジタル入力 |
| **S2 (左内側)** | **GPIO 33** | デジタル入力 |
| **S1 (右内側)** | **GPIO 34** | デジタル入力 |
| **S0 (右外側)** | **GPIO 35** | デジタル入力 |

### ② DRV8825 ステッピングモータドライバ (2基)
| DRV8825 ピン | ESP32 ピン | 備考 |
| :--- | :--- | :--- |
| **M1 (左) STEP** | **GPIO 19** | パルス入力 |
| **M1 (左) DIR** | **GPIO 18** | 方向制御 |
| **M2 (右) STEP** | **GPIO 17** | パルス入力 |
| **M2 (右) DIR** | **GPIO 16** | 方向制御 |

### ③ 2軸ロボットアーム（サーボモータ）
**※ロボットアームの制御はArduino Unoに委譲されたため、サーボモーターはESP32には直接接続せず、Arduino Unoに接続してください。**

### ④ 他モジュールとのシリアル通信接続 (UART連携)
| 通信先機器 | 接続 (送信側 TX -> 受信側 RX) | 備考 |
| :--- | :--- | :--- |
| **Raspberry Pi** | **Pi TX -> ESP32 GPIO 21 (RX2)** | Piからの指令を受信 |
| **Raspberry Pi** | **ESP32 GPIO 22 (TX2) -> Pi RX** | ESP32からの返信 |
| **Arduino Uno** | **ESP32 GPIO 5 (TX1) -> Uno RX** | 起動時の初期化データを送信 |
| **Arduino Uno** | **Uno TX -> ESP32 GPIO 4 (RX1)** | Unoからの返信（必要に応じてレベル変換を推奨） |

## 🚀 使い方・動作手順

### 1. ファームウェアの書き込み
MicroPython本体をESP32にフラッシュします。
```bash
pip install esptool
esptool.py --chip esp32 erase_flash
esptool.py --chip esp32 --baud 460800 write_flash -z 0x1000 ESP32_GENERIC-20240222-v1.22.2.bin
```

### 2. プログラムファイルの転送
`ampy` 等のツールを使用して、作成したPythonスクリプトファイルと `index.html` をESP32に転送します。
```bash
pip install adafruit-ampy
export AMPY_PORT=COM3  # ご自身のPCのESP32シリアルポートに合わせて変更してください

ampy put config.py
ampy put boot.py
ampy put line_follower.py
ampy put web_server.py
ampy put main.py
ampy put index.html
```
> ⚠️ **注意**: `__pycache__/` フォルダはPC側のバイトコードであり、ESP32のフラッシュメモリを無駄に消費するためアップロードしないでください。

### 3. Wi-Fi APモード & Webコンソールの使い方
1. プログラム転送後、ESP32をリセットして起動します。
2. スマホやPCのWi-Fi設定を開き、以下のアクセスポイントに接続します：
   - **SSID**: `zeni`
   - **パスワード**: `hogehoge` (必要に応じて `boot.py` でパスワード変更可能)
3. ブラウザを開き、以下のURLへアクセスします：
   - **URL**: `http://192.168.4.1`
4. **Webコンソールの機能**:
   - **テレメトリ監視**: 走行ステータス、センサ検知状態などがリアルタイムに可視化されます。
   - **コントロール**: `START` / `STOP` などのボタンをクリックし、本体を直接制御できます。
