# マイコン間およびペリフェラル ピンアサイン一覧

このドキュメントは、本プロジェクトにおける ESP32、Raspberry Pi、Arduino Uno 間の接続、および各センサー・モーターのピン割り当てのみを抽出したリファレンスです。

---

## 1. ESP32 (メインコントローラー)

### 走行系・センサー系
| モジュール | 信号・役割 | ESP32 ピン | 備考 |
| :--- | :--- | :--- | :--- |
| **MakerLine** | S3 (左外側) | **GPIO 32** | デジタル入力 |
| | S2 (左内側) | **GPIO 33** | デジタル入力 |
| | S1 (右内側) | **GPIO 34** | デジタル入力 |
| | S0 (右外側) | **GPIO 35** | デジタル入力 |
| **DRV8825 (左)** | STEP (M1) | **GPIO 19** | パルス出力 |
| | DIR (M1) | **GPIO 18** | 方向制御 |
| **DRV8825 (右)** | STEP (M2) | **GPIO 17** | パルス出力 |
| | DIR (M2) | **GPIO 16** | 方向制御 |

### ロボットアーム系
**※ロボットアーム（サーボ）の制御はArduino Unoに委譲されたため、ESP32には直接接続しません。**

### 通信系 (UART)
| 接続先 | 信号・役割 | ESP32 ピン | 内部ポート |
| :--- | :--- | :--- | :--- |
| **Raspberry Pi** | 受信 (RX) | **GPIO 21** | UART2 RX |
| | 送信 (TX) | **GPIO 22** | UART2 TX |
| **Arduino Uno** | 送信 (TX) | **GPIO 5** | UART1 TX (Unoへのデータ送信) |
| | 受信 (RX) | **GPIO 4** | UART1 RX |

## 2. Raspberry Pi (データ送信 / 画像認識連携)

| 役割 | Raspberry Pi ピン | 接続先 (ESP32) | 備考 |
| :--- | :--- | :--- | :--- |
| **データ送信** | **TX** (例: GPIO 14) | ESP32 **GPIO 21** (RX2) | コマンド（'1' など）を送信 |
| **データ受信** | **RX** (例: GPIO 15) | ESP32 **GPIO 22** (TX2) | 状態のフィードバックなど |
| **グランド** | **GND** | ESP32 **GND** | ※必ずGNDを共通化すること |

---

## 3. Arduino Uno (データ受信 / 中継先)

ESP32との通信用ピンです。PCのシリアルモニタ（USB）との競合を避けるため、ピン2やピン3を利用した `SoftwareSerial` での接続を推奨します。

| 役割 | Arduino Uno ピン | 接続先 (ESP32) | 備考 |
| :--- | :--- | :--- | :--- |
| **データ受信** | **D5 (RX)** | ESP32 **GPIO 5** (TX1) | ESP32からのデータを受信 |
| **データ送信** | **D6 (TX)** | ESP32 **GPIO 4** (RX1) | 5V→3.3Vのレベル変換必須 |
| **グランド** | **GND** | ESP32 **GND** | ※必ずGNDを共通化すること |

### ロボットアーム系 (サーボモーター)
| 役割 | Arduino Uno ピン | 備考 |
| :--- | :--- | :--- |
| **Joint 1 (Base / 肩)** | **例: デジタル Pin 9** | PWM出力 (Servoライブラリ等を使用) |
| **Joint 2 (Elbow / 肘)**| **例: デジタル Pin 10**| PWM出力 (Servoライブラリ等を使用) |
| **サーボ電源** | **外部 5V電源** | Unoの5Vピンからの給電は容量不足になるため外部電源を推奨 |
